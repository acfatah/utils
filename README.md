A collection of common small ES6 or Javascript utility function snippets that can 
be copy pasted into any web projects.

## Features

- Written in TypeScript.
- ES6 compatible.
- Can be access from CDN.
- Can be copy pasted into any project.
- Compatible both browser and node environment.

### Using package managers

- Use any package manager: `npm`, `yarn`, `pnpm` or `bun`.

E.g, `bun install @acfatah/utils`.

### Manual Copy Paste

We follow convention that the source for utility functions reside under `lib`, 

For TypeScript, the sources are under `src/lib` while for the ES6 modules, the
sources are under `dist/lib`.

Just copy paste the functions needed to run them.
